
# Lab 4b: Client-Side Scripting (JSON and jQuery)

**Course:** BIC21203 Web Development

## Project Description

This lab demonstrates how to create, retrieve, and display JSON data using JavaScript and how to manipulate HTML elements using jQuery.

## Files Included

| File | Description |
|---|---|
| books.json | Contains information about two books. |
| books.html | Retrieves and displays JSON data using fetch(). |
| jquery-dom.html | Demonstrates DOM manipulation using jQuery. |

## Requirements

- Visual Studio Code
- Google Chrome or another modern web browser
- Live Server extension
- Internet connection for the jQuery CDN

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `books.html` and select Open with Live Server.
5. View the displayed book information in your browser.
6. To test jQuery, open `jquery-dom.html` using Live Server.
7. Click the button to display the alert message.

## Learning Outcomes

- Create and structure valid JSON data.
- Retrieve JSON data using the JavaScript fetch() API.
- Display selected JSON data on a webpage.
- Understand DOM manipulation using native JavaScript and jQuery.
- Handle button click events using jQuery.
